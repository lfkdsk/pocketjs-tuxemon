# Feature status

What the Pocket Tuxemon port can do today, system by system.

- **Done**: on `main` and verified by a test, a journey replay or an upstream comparison.
- **Partial**: works within the limits noted.
- **Planned**: not on `main` yet. "In progress" means someone is working on it now.
- **Missing**: an audited upstream system is not imported; its row explains why it is not reachable in this campaign.

Per-action numbers come from the import coverage report,
[reports/G1-coverage.md](../reports/G1-coverage.md). It is regenerated by `bun run import`.

The volatile probe moves the minute inside the hour and rejects any character that depends on it (none do today) (`battle/preview-hooks.ts`). Presentation only: the session state is identical with and without it. A map's preview takes a few frames to compute after a story change, during which the previous one stays on screen.
