# Feature status

What the Pocket Tuxemon port can do today, system by system.

- **Done**: on `main` and verified by a test, a journey replay or an upstream comparison.
- **Partial**: works within the limits noted.
- **Planned**: not on `main` yet. "In progress" means someone is working on it now.

Per-action numbers come from the import coverage report,
[reports/G1-coverage.md](../reports/G1-coverage.md). It is regenerated by `bun run import`.

| All 263 maps imported, terrain matching Tuxemon's renders | Done | One-way ledges, animated tiles and 16×32 walkers. Maps load on demand from self-describing shards. See [architecture](architecture.md) |
| Map transfers | Done | 1,037 of 1,049 `transition_teleport` uses are native and 3 malformed landings are repaired deterministically. The 9 dropped uses belong to source events blocked by invalid/fixed-false guards or zero-area geometry; the transfer lowering itself supports every reachable player transfer |
| Seamless outdoor world | Partial | The project defaults to `seamless-v1`. Of 258 coordinate-preserving outdoor openings, 253 runtime-direct `playerTouch` transfers carry stable portal IDs and cross atomically in eight ticks without a fade; five Route 3 openings have an unreachable source facing and stay legacy. The 39 portal-only openings, direction-only seams, gaps, rejected contacts, indoor/faint/story transfers and every unmarked transfer also stay legacy. The kit's world renderer stays mounted across both placed outdoor and unplaced indoor maps, so the game no longer keeps a stale last-known placement adapter. It shows neighbouring ground, upper layers, animated tiles and the neighbour NPC preview (next row) across 71 seams while keeping map and texture caches bounded. A completed seamless entry freezes the just-left map's painted NPCs in the saved `mapRuntime.leftMap` until the next entry or distance eviction, avoiding a preview jump immediately behind the player. Map-entry NPC-party clearing, destination banner, weather and encounter-step semantics match legacy; source clock/daylight and audio advance during the eight visible crossing ticks, whereas legacy freezes clock/daylight during its fade. See [importer](importer.md) and [verification](verification.md) |
| Neighbour NPC preview | Done | The world renderer previews the characters on visible neighbour maps by entering each map in a sandbox (a private copy of the state, first target tick), so the people across a seam already stand where they will be after the crossing, and the map left behind stays frozen. The cache key leaves out step countdowns and the running clock but holds the calendar day, the hour and the weather, which is everything a `time_is` condition or `update_time` can read; a new hour or a weather change recomputes the previews. The volatile probe moves the minute inside the hour and rejects any character that depends on it (none do today) (`battle/preview-hooks.ts`). At the new-game state 1,158 events are previewable, 7,012 hidden (they paint nothing on entry) and 5 rejected (`entry-transfer` on `eclipse_park` and `eclipse_park_cave`): 99.6% of the events that paint. No mainline (`spyder_*`) event is rejected at any chapter (`verify:preview:coverage`). Six mainline seams are checked at both viewports in four frames each (`goldens:preview-seam`): every character the session state puts on screen is found at its place against its sprite image, and a scan of the whole frame finds no second copy of any of them. Presentation only: the session state is identical with and without it. A map's preview takes a few frames to compute after a story change, during which the previous one stays on screen. See [importer](../reports/G1-coverage.md) and [verification](verification.md) |

| Saving and loading the game | Done | START opens the save menu, a GameView overlay that adds no per-frame work. Desktop saves to three slot files, the browser to three local-storage slots, and every target can export or import a save code (the only channel on PSP). A save is the kit's snapshot: map, player, story variables, bag and gold, party and kennel, clock, weather, daylight tint, audio state, the current map's characters, and the frozen just-left seamless-map snapshot.
